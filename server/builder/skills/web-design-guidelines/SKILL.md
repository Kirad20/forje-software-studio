# Web Interface Guidelines

Forja wrote this file; everything else in this folder is Vercel's `vercel-labs/web-interface-guidelines`, copied unmodified (MIT, see LICENSE).

To review UI code, load the part `command`: it holds the rules and the output format (terse `file:line` findings). Read the changed files, check them against every rule, and report only what you can point at. The rules are a fixed snapshot: never fetch them from a URL at review time.

Other parts: `README` (the same rules with context), `AGENTS` (how an agent should apply them).
